# Explicit withdrawal (unranked private tournaments)
Any human may explicitly withdraw from a fixed-round tournament before its final completed result. The UI requires opening the withdrawal disclosure and confirming. Temporary disconnects, closing the browser and the ordinary leave-table action do not withdraw a seat. The authenticated server action uses the same revision CAS; terminal withdrawal freezes the engine, clears ready votes and rejects subsequent mutations and new joins. Finished-round scores remain; unfinished rounds score nothing; no final winner is declared. Returning members can see the frozen summary until the existing room expiry. This is intentionally not a forfeit or ranked penalty. No durable ranking, substitute seat, automatic timeouts or schema changes.
