# Tournament continuation consent
Fixed-round private tournaments require each human seat to vote ready independently. Bots never vote. The existing rematch command is interpreted as an affirmative vote for compatibility; rematch-ready supports explicit withdrawal. The final affirmative vote deals the next round atomically using the existing revision CAS. Stale commands fail and clients refresh; a vote cannot be applied to a different round. No timeout or automatic consent. Endless rooms retain their legacy rematch behavior. Leaving a fixed tournament may strand the remaining seats; they can leave and create a fresh table. Durable forfeits and host handoff remain future work.
Native share is exposed when supported; the existing copy invitation remains available. No seat token is included. No new analytics or external requests.
