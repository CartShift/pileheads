# @pileheads/game-protocol
Private, types-only contract for the current HTTP room API. Web and future mobile clients share redacted Room / RoomGame / PublicSeat DTOs without importing browser code or trusted full state. The package does not contain networking, tokens, database code or authorization. Fields added to the original web declaration are optional for compatibility with local views/older responses. Only the authoritative server decides what may be disclosed. Wire moves use blind slot indexes rather than hidden card IDs; the server remains responsible for validation. In Phase 6, add version negotiation, runtime schema validation and a shared transport with injectable fetch/WebSocket and mobile lifecycle support; this PR deliberately does not change the wire format.
